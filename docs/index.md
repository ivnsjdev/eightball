# 8 Ball

8 Ball is a fortune-telling ball for Apple Watch: ask a yes-or-no question, shake
your wrist, and read the answer. Twenty classic replies, a ball that really tumbles
in 3D, twelve skins, twelve emblems, and 32 languages — on the watch alone, with no
iPhone app needed.

It is a one-time purchase with nothing else to buy, and it has no network code of any
kind. There is no account, no server, no advertising, no analytics, and no tracking.
The app never asks for your question and has nowhere to send it.
